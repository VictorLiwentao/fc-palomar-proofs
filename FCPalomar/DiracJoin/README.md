# Dirac's joins of odd cycles: Erdős Problems 917 (Dirac, Erdős 3 | k) and 1032 (Dirac 6-critical)

The join of q >= 1 disjoint copies of an odd cycle C_m (m >= 3) is 3q-critical: its chromatic number is 3q, and deleting any vertex or any edge lowers it. This gives three classical lower bounds. Dirac: f_6(4n+2) >= 4n^2+8n+3 for n >= 1 (Erdős Problem 917). Erdős: if k >= 3 and 3 | k, then f_k(n) >= ½(1 − 1/(k/3))n^2 + n for every n = m·k/3 with m odd and m >= 3 (Erdős Problem 917). Dirac: for infinitely many n there is a 6-critical graph on n vertices with minimum degree > n/2 (Erdős Problem 1032). Here f_k(n) is the largest number of edges of a k-critical graph on n vertices, and k-critical means both vertex- and edge-critical.
