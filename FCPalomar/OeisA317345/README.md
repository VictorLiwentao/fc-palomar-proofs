# OEIS A317345: Hanna's mod-10 periodicity, with a general p-adic theorem

For natural numbers a, b let A(x) = Σ a(n)xⁿ/n! with A(0) = 1 satisfy [xⁿ] exp(n^a x)/A(x)^(n^b) = 0 for every n ≥ 1. The package proves that A exists and is unique; that for every prime p with 1 ≤ b < pa each a(n) is p-integral and a(n) ≡ a(n mod p) (mod p); and so that a(n) is an integer when 1 ≤ b < 2a. For OEIS A317345 (a = 3, b = 2) this gives Paul D. Hanna's 2018 conjecture a(5n + k) ≡ [1, 1, 5, 5, 5](k) (mod 10), and for OEIS A317343 (a = 2, b = 1) the pattern [1, 1, 3, 3, 5]. In both cases Lean checks the residues of a(0), …, a(4) modulo 2 and 5 by kernel computation. Hanna's remark that log A(x) has integer coefficients is not proved here. Context: the known route to Hanna's claim is conditional. Bala's theorem (2017 note on OEIS A047974) gives a(n + k) ≡ a(n) (mod k) for every k when log A(x) has integer coefficients. Hanna observed that integrality numerically for A317345 and A317343, whose logarithms are A317346 and A317344, but it is unproved. The theorem here needs no such input. With 1 ≤ b < a it applies to exp(F) for every o.g.f. F in Hanna's family [x^n] exp(n^a x − n^b F(x)) = 0 (A317344, A317346, A317347, A319941–A319944, and the entries for a ≤ 8 that Hanna added in March 2026, such as A393854 and A393861). For each of them it gives integer e.g.f. coefficients and a(n) ≡ a(n mod p) (mod p) for every prime p.
