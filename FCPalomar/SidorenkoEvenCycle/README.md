# Sidorenko's inequality for even cycles

For every k >= 2 and every finite graph G on a nonempty vertex set, t(K_2, G)^{2k} <= t(C_{2k}, G): even cycles have Sidorenko's property (Sidorenko 1993). The Lean proof avoids eigenvalues; it uses Cauchy–Schwarz and log-convexity of the walk counts ||A^j 1||^2.

- Formal Conjectures statement: `SidorenkoConjecture.sidorenko_conjecture.variants.even_cycle` in [`FormalConjectures/Wikipedia/SidorenkoConjecture.lean`](https://github.com/google-deepmind/formal-conjectures/blob/691719db2653905d5fa0775408370fb058e4c59f/FormalConjectures/Wikipedia/SidorenkoConjecture.lean) (copied verbatim into `Challenge.lean`).
- Mathematics: A. Sidorenko, A correlation inequality for bipartite graphs, Graphs Combin. 9 (1993), 201–204; A. F. Sidorenko, Inequalities for functionals generated by bipartite graphs, Diskret. Mat. 3 (1991), 50–65 (English: Discrete Math. Appl. 2 (1992), 489–504).
