# OEIS A258377–A258381: Bala's 2-adic periodicity for the type-B series

For N ≥ 1 let A_N(z) = 1 + a(1)z + ⋯ be the series with A^(N+1)(z) = 1/(1 − z)·(BINOMIAL(BINOMIAL(A(z))))^N, where BINOMIAL is the binomial transform; A258377–A258381 are N = 1, …, 5. The package proves for every N that A_N exists, is unique and has integer coefficients, that every a(n) is odd, that a(n + 2^(k−1)) ≡ a(n) (mod 2^k) for all k ≥ 1, and that for k ≥ 3 the least period of a(n) mod 2^k is exactly 2^(k−1) if and only if N ≡ 1 or 2 (mod 4). This settles Peter Bala's 2017 observations on the five entries: odd terms for A258377, A258379 and A258381, period 2^(k−1) for A258377 and A258381, terms ≡ 1 (mod 4) for A258378 and ≡ 1 (mod 8) for A258380, periods dividing 2^(k−1) for A258378–A258380, and his worked examples modulo 4, 8, 16 and 32. His remarks on residues modulo 3 and 5 are not covered.
