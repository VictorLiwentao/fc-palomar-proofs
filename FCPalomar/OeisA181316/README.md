# OEIS A181316 and A180606: Hanna's q-integer power conjecture, with the sharp form

Write [n]_q = 1 + q + ⋯ + q^(n−1). The package proves that exp(Σ_{n≥1} (q−1)[n]_q^(n−1) xⁿ/n) has integer coefficients for every integer q > 1, as Paul D. Hanna conjectured in 2010 (OEIS A181316), and for every integer q ≠ 1. It proves the sharp form: for integers q and c, exp(Σ c[n]_q^(n−1) xⁿ/n) has integer coefficients if and only if every prime dividing q − 1 divides c. The same holds for any exponent sequence e(n) in place of n − 1 with e(pM) ≡ e(M) (mod φ(p^k)) whenever p is prime and p^k divides pM, and e(n) ≥ 1 for n ≥ 2; with e(n) = n this gives Hanna's 2009 claim on A155206 and A155210. The cases q = 3 (A181316) and q = 2 (A180606) are stated separately. The converse gives Hanna's notes in A155206 and A155210 that dividing by (m − 1)^n instead of (m − 1)^(n−1) gives fractional coefficients.
