# Counterexamples to five OEIS conjectures (A333564, A034171, A298799, A382407, A399793)

The package states five conjectures from OEIS entries exactly and proves each false by an explicit, kernel-checked witness. (1) Bala's general clause on A333564, for a(r,s;n) = 2^(rn) Σ_{j<sn} (−1)^(sn−1+j) C(n+j,j)^r with the modulus p^(3k) for primes p ≥ 3, fails at (r,s,p,n,k) = (2,1,3,1,1). (2) Bala's congruence c(pn) ≡ c(n) (mod p²) outside his exception set fails for A034171 at p = 7, n = 50, and (3) for A298799 at p = 19, n = 362, where a(6878) has 9841 digits. (4) Huber's conjecture that a(k) = 0 exactly for k in {2, 4, 8, 13} ∪ {3^j} ∪ {5·3^j} fails at k = 10 for A382407; the package also proves the 'if' direction of the amended set. (5) The conjecture a(n) = ℓ(n) for n ≥ 13 on A399793 fails for 13 ≤ n ≤ 17, where explicit bad sets give a(n) > ℓ(n). The counterexamples for A382407 and A399793 are visible in those entries' own data.
