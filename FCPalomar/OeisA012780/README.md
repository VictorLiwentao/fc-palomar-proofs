# OEIS A012780: Bala's periodicity conjecture for arcsin(tan x)

Let a(n) = (2n+1)! [x^(2n+1)] arcsin(tan x) (OEIS A012780). The package proves that every a(n) is an integer and Peter Bala's 2026 conjecture that a(n) mod k is eventually periodic with period dividing φ(k), for every k ≥ 1. It also proves the prime-power congruences behind it: a(n + 2^(e−1)) ≡ a(n) (mod 2^e) for all n, and a(n + φ(p^e)) ≡ a(n) (mod p^e) for odd primes p and 2n ≥ e, and the conjecture with that explicit pre-period. It also proves that a(n + 2) ≢ a(n) (mod 8) for every n, so the Carmichael function λ(k) cannot replace φ(k). Bala's φ(k)-periodicity conjectures for exponential generating functions are recent research targets: Kallat proved Bala's conjectures for A158690 (arXiv:2609.07238), and Blanco Gómez proved the φ(k)-period for the Euler numbers A000364, where Bala's stronger claim of pure periodicity fails (Zenodo 23150466, Theorem 2.2). Kallat's general theorem gives λ(k)-periods, so by the mod-8 result it does not cover A012780.
